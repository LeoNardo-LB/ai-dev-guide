# 1. manifest 单源与生成派生

| 字段 | 值 |
|------|----|
| 状态 | 已接受 |
| 日期 | 2026-08-21 |
| 决策者 | 用户 + agent |

## 上下文

v1.1 中索引表、目录树、裁剪表分散在四处手工副本，结构上必然漂移；增删文档需要人工同步四个位置。

## 决策

全部文档元数据（路径/级别/用途/触发/裁剪组/预算）集中于 manifest.yaml；AGENTS 模板索引、README 总览、system-design 总表、onboarding 裁剪表由 gen-index.py 从 manifest 生成（写入 GEN 标记段）；check.sh 门禁 5 校验幂等。

## 备选方案

| 方案 | 理由 | 否决原因 |
|------|------|----------|
| manifest 生成（选定） | 单源零漂移 | — |
| 手工副本 + 人工同步 | 自由度高 | v1.1 已实证必漂移 |
| 完全生成文档树 | 更彻底 | 正文必须手写，生成器只应搬运元数据 |

## 后果

正面：增删文档只改 manifest 一行；门禁 5 保证生成物与源一致。
负面：manifest 格式受严格子集约束；新增字段需同步改生成器。
