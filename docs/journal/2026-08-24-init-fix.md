## 目标

用户问「现在能按 README 执行 init.sh 初始化了吗」——以端到端实测作答，实测暴露两个缺陷即场修复。

## 过程与证据

1. 实测矩阵：默认部署 ✓ / --dir mydocs ✓（41 处前缀正确替换、零残留）/ --no-ui+--no-example ✓（裁剪 3 份）/ 已有 AGENTS.md → 生成 .new 供合并 ✓ / 重跑幂等（backlog 用户内容保留）✓ / 部署侧 release-version 与 new-batch 独立可用 ✓
2. 缺陷一（实测发现）：部署复制了 init/upgrade/gen-index——依赖源仓 manifest，在目标项目内不可运行；修正为仅复制运行时子集（check/_gates/new-batch/release-version）
3. 缺陷二（实测发现）：--no-ui 时模板正文手写的 ui-conventions 链接悬空（GEN 索引尊重裁剪组，手写正文不尊重），清洗器未覆盖生成的 AGENTS.md；修正 scrub 范围加入 $OUT
4. 修复后三场景全绿：A --no-ui 全新部署（18 处清洗）门禁过 / B 默认部署过 / C 源仓 selftest 过
5. 方法教训：测试长输出脚本时禁止管道接 head（SIGPIPE 中途杀死脚本制造假失败）——本轮首测的「失败」即此伪象，改重定向文件后重现真缺陷
